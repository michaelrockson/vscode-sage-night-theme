# Sage Night

A muted dark theme for VS Code: sage-green keywords, soft-green functions and types, warm terracotta strings, orange parameters and blue numbers on a near-black background.

| Role | Color |
| --- | --- |
| Background | `#151515` |
| Text | `#c0c0b8` |
| Keywords | `#4d9375` |
| Functions, types | `#80a665` |
| Strings | `#c98a7d` |
| Parameters, constants | `#c99076` |
| Properties | `#bd976a` |
| Numbers | `#6394bf` |
| Comments | `#6a8372` (italic) |

## Install

Install the `.vsix`: open the Extensions view, click `…` → **Install from VSIX…**, pick the file, then choose **Sage Night** under **Preferences: Color Theme**.

Or from the folder: copy it into `~/.vscode/extensions/sage-night-theme` and restart VS Code.
